# ODYSSEY — 귀환의 항해

오디세우스의 귀환 여정을 탐색하는 한국어·영어 SVG 입체 아틀라스. 15개 장, 14개 장소, 스토리 항해와 자유 탐색, 장면별 탐색 지점으로 구성한다. 마지막 두 장은 같은 이타카를 공유한다.

## 언어 전환

헤더의 **한국어 / English** 버튼으로 언제든 전환한다. 첫 방문에는 브라우저의 우선 언어가 한국어이면 한국어, 그 외에는 영어를 표시한다. 직접 고른 언어는 이 브라우저에 저장되어 새로고침 후에도 유지된다. 저장이 차단된 환경에서도 현재 화면의 전환은 작동한다.

15개 장의 이야기, 지도 지명과 탐색 설명, 설정, 출처와 보조 서사를 모두 번역한다. 전환 시 현재 장, 발견 지점, 장면 진행률과 카메라를 유지하며, 문서 언어·제목·접근성 설명도 갱신한다. 항해를 초기화해도 언어 선택은 유지한다.

번역은 `src/content/language.ts`와 `src/content/chapters.en.ts`에서 관리한다. `npm run test:unit`은 번역 누락·장면 데이터 일치·언어 선택 저장을 검사한다. `dist`를 포트 4173으로 제공한 뒤 `python scripts/check-language.py`를 실행하면 Playwright Chromium으로 전환, 저장 지속성, 전체 장과 모바일 배치를 검증한다.

## 바로 실행

**`dist/ODYSSEY.html`을 저장한 뒤 브라우저에서 연다.**

React 런타임, 애플리케이션, CSS를 한 파일에 포함한 실행본이다. 실행 시 패키지 설치, API 키, 계정, 외부 이미지, 외부 폰트, 네트워크 호출이 필요하지 않다. HTML 소스 미리보기가 표시되는 파일 뷰어에서는 파일을 저장한 뒤 브라우저로 다시 연다.

브라우저나 조직 정책이 로컬 HTML 실행을 제한하는 경우에는 승인된 정적 웹 서버에서 `dist` 폴더를 제공한다. 일반적인 로컬 개발 환경에서는 다음 명령으로 정적 서버를 열 수 있다.

```bash
python -m http.server 8080 --directory dist
```

위 명령 사용 시 브라우저 주소는 `http://localhost:8080`이다. 생성 환경에서는 브라우저 탐색 정책으로 `file://`와 서버 주소 접근이 차단되어, 동일한 실행본을 Chromium 문서에 직접 주입하는 방식으로 검증했다. 파일을 직접 여는 과정과 실제 배포 URL은 검증하지 않았다.

## 조작

| 조작 | 동작 |
|---|---|
| 항해 시작 / 다음 장 / 이전 | 장면과 선박을 연결하는 항해 |
| 타임라인 / 여정 목록 / 지도 지명 | 원하는 장으로 이동 |
| 드래그 / 휠 / 두 손가락 확대 | 지도 이동과 확대·축소 |
| 회전 버튼 / Shift + 드래그 | 제한된 범위에서 시점 회전 |
| 전체 지도 / 항해 따라가기 | 전체 조망과 선택 장면 추적 복원 |
| 지도 탐색 지점 / 우측 발견 목록 | 설명 표시와 해당 물체 접근 |
| 장면의 순간 슬라이더 | 선택된 사건의 시각적 단계 변경 |
| 설정 / 일시정지 | 모션 축소, 표시 품질, 자동 항해, 재생 제어 |
| ← / → / Space / Esc | 장 이동 / 재생·정지 / 설명·대화상자 닫기 |

모바일에서는 `이야기 펼치기`로 하단 설명을 열고, `이야기 접기`로 지도 공간을 확보한다. 자동 항해는 사용자가 설정에서 켰을 때만 시작한다. 운영체제의 모션 축소가 활성화된 경우 반복 동작과 자동 항해를 제한한다.

## 구현 내용

전체 세계는 x·y·z 정점과 면으로 모델링하고, 카메라 좌표 변환 후 SVG path로 투영한다. Canvas, WebGL, Three.js, 배경 래스터 이미지로 입체 장면을 대체하지 않는다. 광원과 면의 법선으로 명암을 계산하고, 가시성 판정과 카메라 깊이 정렬을 수행한다.

선박에는 선체 측면, 갑판, 판재, 돛의 곡면 분할, 돛대, 밧줄, 노, 인물 실루엣이 있다. 여정에 따라 함대·단독 선박·난파 잔해·뗏목 상태를 사용한다. 동굴의 전경과 내부, 키르케의 궁전과 변신, 깊이가 있는 소용돌이, 움직이는 스킬라, 지붕을 연 이타카 궁전을 별도 장면으로 구성한다.

해협 슬라이더는 배의 위치·괴물의 접근·소용돌이 깊이에 함께 반영된다. 이타카에서는 직조기, 올리브나무와 활의 시험을 살펴볼 수 있고, 페넬로페와 텔레마코스의 보조 서사를 별도 장면으로 연다.

현재 장과 방문 기록, 모션·품질 설정은 브라우저의 localStorage에 저장한다. 접근 거부와 손상된 값은 기본 상태로 처리하며, 저장 실패가 항해를 중단하지 않는다. 자동 항해 활성 상태는 저장하지 않는다.

## 개발 실행

Node.js와 npm이 있는 환경에서 다음 명령을 실행한다. 외부 패키지를 내려받을 수 있어야 한다.

```bash
npm install
npm run dev
```

정식 타입 검사와 Vite 빌드:

```bash
npm run check
npm run build
npm run preview
```

현재 전달본의 실행 HTML은 외부 패키지 다운로드 없이 생성한 **대체 오프라인 빌드**다. 생성 환경에서 `npm install`이 차단되어 정식 React 타입 패키지를 포함한 전체 타입 검사 및 Vite 빌드는 실행하지 못했다. 이를 통과한 빌드로 표시하지 않는다.

TypeScript가 로컬 의존성 또는 전역 설치로 존재하면 다음 명령으로 소스에서 단일 HTML을 다시 생성할 수 있다.

```bash
npm run build:offline
npm run check:core
npm run test:unit
```

`build:offline`은 TS/TSX 변환과 번들링을 수행한다. 전체 의미 기반 타입 검사의 대체 수단이 아니다. `check:core`는 React 의존성이 없는 그래픽·콘텐츠·저장 모듈의 의미 기반 타입 검사다.

```text
src/content/       15개 장, 탐색 지점, 병행 서사, 저장 처리

```

## 콘텐츠 근거

장 구성과 서사 핵심은 사용자 제공 명세 `docs/SPEC.md`를 기준으로 한다. 설명과 짧은 서술은 새로 작성한 각색이다. 원문 직접 인용, 특정 번역본의 대사, 확인된 영화 장면으로 표시하지 않는다. 원전의 절·행 단위 대조 주석은 포함하지 않는다.

지형·궁전·배의 외형, 색감과 동작은 웹앱을 위한 시각적 해석이다. 항로는 실제 지리적 위치를 확정한 지도가 아니다. 인물의 배우 외형이나 영화 스틸을 사용하지 않는다.

## 남아 있는 제약

깊이 처리는 SVG의 면 정렬과 대표 장면의 분할 설계를 사용한다. 일반적인 3D 엔진의 픽셀 단위 깊이 버퍼가 아니므로 복잡하게 교차하는 면, 동적 객체와 지형의 경계에서는 일부 가림 오차가 생길 수 있다. 자유 회전 범위를 제한한 이유이기도 하다.

고품질 모드의 프레임 갱신 목표는 60fps지만, 지속 60fps를 측정하거나 보장하지 않았다. 자동 모드는 계산 부하가 높을 때 세부도와 갱신 빈도를 낮춘다. Safari·Firefox, 실제 모바일 기기, 숨김 탭 수명주기, 브라우저 원점별 저장 지속성은 추가 확인 대상이다.

공개 서버 배포는 수행하지 않았다. 런타임은 정적 파일만 필요하며, 연결된 AppDeploy의 이번 실행 도구 목록에는 배포 실행 액션이 노출되지 않았다.

## 라이선스

장면 모델과 설명은 이번 구현을 위해 작성했다. 오프라인 React·React DOM·Scheduler 런타임의 MIT 고지는 `licenses/react-MIT.txt`와 단일 HTML 안에 포함했다. 폰트 파일은 포함하지 않으며, 사용자의 기기에 설치된 글꼴을 사용한다.
